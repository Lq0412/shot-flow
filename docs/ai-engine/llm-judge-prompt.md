# LLM 视觉判断 Prompt 工程

> "土豪模式"——用大模型判断照片好坏的 Prompt 设计思路

## 背景

除了传统 CV 和 AI 模型评分，还可以用视觉大模型（如豆包/Seed）直接"看"照片并给出判断。

优势：
- 不需要本地模型
- 理解能力远超传统评分
- 可以用自然语言解释原因

劣势：
- 需要联网
- 按张计费
- 速度较慢（1-3 秒/张）

## "骨架 vs 皮肉" Prompt 框架

### 核心分类

**骨架（不可修复）→ 直接淘汰：**
- 焦点不实（对焦失误、整体模糊）
- 表情失误（眨眼、怪表情）
- 时机错过（关键动作已过）
- 构图严重失衡（切头、切手）

**皮肉（可修复）→ 通过并标记：**
- 乱发、碎发
- 皮肤瑕疵、痘痘
- 路人入镜（可后期消除）
- 轻微色偏（可后期校正）

### Prompt 结构

```
系统角色设定：
  你是一位资深摄影选片师，擅长人像、婚礼、活动摄影。

核心判断框架：
  对每张照片，先评估"骨架"（不可修复的硬伤），再评估"皮肉"（可修复的软伤）。

  骨架有硬伤 → 立即淘汰，说明原因
  骨架没问题 → 通过，如有皮肉问题标记"可修复"

力度控制：
  [标准] 只淘汰明确的骨架硬伤
  [进阶] 更严格，对锐度和构图要求更高

输出格式：
  {
    "verdict": "pass" | "reject",
    "reason": "...",
    "fixable_issues": ["..."],
    "confidence": 0.0-1.0
  }

反模式（必须避免）：
  - 不要写"平庸"、"没有亮点"——那些是借口，不是观察
  - 不要因为"构图不是最优"就淘汰——选片不是选艺术品
  - 不要忽略 EXIF 方向信息——旋转过的照片不要误判

边缘案例示例：
  Case A: 背影照 → 不是"没拍到脸"，可能是创意选择 → 通过
  Case B: 闭眼大笑 → 可能是真实情绪瞬间 → 不一定是"闭眼"
  Case C: 运动模糊 → 如果主体清晰背景模糊，是追焦技巧 → 通过
  ...
```

## 自适应并发限流

大模型 API 有速率限制，需要动态调整并发：

```
初始并发 = 10

收到 429 (Rate Limit) 响应：
  → 并发减半（最低 1）
  → 记录最后 429 时间

连续 30 次成功 + 距离上次 429 > 10 秒：
  → 并发 +1（最高回到初始值）
```

### 退避重试

```
失败时：
  1. 等待 1 秒重试
  2. 再失败等待 2 秒
  3. 再失败等待 4 秒
  4. 最多重试 3 次，之后标记该图片为"判断失败"

注意：不是全部失败就崩溃。200 张照片中有 3 张判断失败，
     这 3 张标记为"需要人工判断"，其余继续处理。
```

## 费用控制（桌面版缺失，鸿蒙版必须加）

### 问题

2000 张照片全跑 LLM 可能花费上百元。用户不知道花了多少，不敢用。

### 解决方案

```
开始前：
  - 显示预估费用（照片数 × 单价）
  - 设置预算上限（默认 ¥20）

进行中：
  - 实时累计已花费
  - 到达预算 80% → 警告
  - 到达预算 100% → 暂停，等待确认

结束后：
  - 显示实际花费
  - 记录到本地，下次默认预算 = 上次实际花费 × 1.5
```

## 对鸿蒙 App 的应用

- 土豪模式作为付费增值功能
- 新用户赠送 50 张免费额度
- 按量计费（¥0.05-0.10/张），不纳入订阅
- 费用透明，预算可控
