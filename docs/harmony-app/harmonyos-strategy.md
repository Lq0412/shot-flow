# 鸿蒙 App 战略方案

> 来源：片刻桌面版项目规划文档，针对鸿蒙平台调整

## 战略决策摘要

| 决策项 | 结论 |
|--------|------|
| **目标平台** | HarmonyOS 5.0+ 原生 App（ArkTS + ArkUI） |
| **AI 处理策略** | **全云端 AI**（鸿蒙端只做 UI/交互/文件管理） |
| **激励计划目标** | 新应用 ¥3,000（月活≥400 + 评分>3） |
| **上架截止** | 2026-09-30（需预留 1 周审核 → 最晚 09-23 提交） |
| **剩余开发时间** | **约 3.5 个月**（从 6月7日 算起） |

## 鸿蒙激励计划 2026 关键规则

| 规则 | 详情 |
|------|------|
| 报名截止 | 2026-09-25 |
| 上架截止 | 2026-09-30（正式上架，非提交审核） |
| 激励金额 | 新应用 ¥3,000/个 |
| 新应用评选标准 | ① 任一自然月有效月活≥400；② 用户评分>3 且评分数≥10 |
| 技术要求 | 正式上架至 HarmonyOS 5.0+ 华为应用市场 |

**月活 400 的解读**：按华为统计规则（去重活跃设备），需要至少 400 个不同华为手机用户在某个月打开过 App。

## 鸿蒙端技术栈

| 模块 | 技术 | 说明 |
|------|------|------|
| **UI 框架** | ArkUI（声明式） | 列表、Grid、Swiper、Stack、Canvas |
| **语言** | ArkTS | TypeScript 超集，鸿蒙原生语言 |
| **照片选择** | `photoAccessHelper.PhotoViewPicker` | 无需授权即可访问相册 |
| **EXIF 读取** | `image.createImageSource()` + `imagePropertyKey` | 读取拍摄时间、焦距、光圈等 |
| **水印渲染** | `Canvas` + `CanvasRenderingContext2D` | 绘制品牌 Logo + EXIF 信息叠加 |
| **图片导出** | `image.createImagePacker()` | 编码输出 JPEG/PNG |
| **状态管理** | `@State` / `@LocalStorageProp` / `AppStorage` | 擂台状态、分组数据 |
| **网络请求** | `@ohos.net.http` | 上传图片到云端、下载 AI 分析结果 |
| **本地存储** | `@ohos.data.preferences` | 用户偏好、最近使用的文件夹 |
| **手势/键盘** | `GestureGroup` + `KeyEvent` | ←/→ 擂台快捷键 |

## 隐私策略

- **极速模式（本地）**：鸿蒙端用 ArkTS 实现基础感知哈希分组，**不传云端**
- **专家/土豪模式（云端）**：上传缩略图（最大 1024px）到云端分析，原图不动
- 上传前需用户确认隐私声明

## 云端成本估算

- 2C4G 服务器：~¥100-200/月
- 不带 GPU：DINOv2-Small 在 CPU 上约 200ms/张
- 首月免费试用额度基本够 MVP 测试

## 鸿蒙端 vs Web 端优势

| 优势 | 说明 |
|------|------|
| **零安装门槛** | 华为应用市场一键安装 |
| **原生相册集成** | PhotoPicker 直接选照片 |
| **原生手势** | 左右滑动/缩放/双击 |
| **分享集成** | 直接分享到微信/朋友圈/小红书 |
| **系统级 Dark Mode** | 跟随系统设置，无需额外开发 |
| **无安全警告** | 应用市场安装，vs .bat 安全警告 |
| **华为生态加分** | 鸿蒙激励计划 + 可能的官方推荐位 |
