# MVP 功能范围与时间线

> 目标：2026-09-30 前上架华为应用市场

|---|------|---------|---------|
| 1 | **相册导入** | PhotoPicker + photoAccessHelper | 1 周 |

## MVP 验收标准

### 功能验收
- [ ] 能从相册选择照片（≥100 张）
- [ ] 云端 AI 初筛准确率 ≥ 85%（模糊/曝光/闭眼）
- [ ] 分组正确率：同一连拍序列的 90%+ 归入同组
- [ ] 擂台 PK 流畅度：左右切换 < 200ms
- [ ] 水印渲染正确：至少 2 种样式可用
- [ ] 进度保存/恢复正常
- [ ] 无崩溃（Monkey 测试 1000 次操作）

### 上架验收
- [ ] HarmonyOS 5.0+ 兼容
- [ ] 华为应用市场审核通过
- [ ] 隐私政策 + 用户协议页面
- [ ] App 备案证明（中国大陆要求）
- [ ] 月活≥400（目标 3 个月内达到）
