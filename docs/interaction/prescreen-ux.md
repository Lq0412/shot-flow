# 智能初筛与复核交互

> AI 自动筛掉技术问题照片，用户可复核恢复

## 初筛机制

### 双路径淘汰

**路径一：绝对淘汰（单图级）**
- 严重模糊（Laplacian 方差 < 阈值）
- 严重过曝/欠曝（直方图分析）
- 明显闭眼（InsightFace EAR 检测）

**路径二：相对淘汰（组内排名）**
- 同组内综合评分最低的 N 张
- 不是单看分数，而是看组内相对位置

### 综合评分公式

```
composite = aesthetic × 0.50 + subject_sharpness × 0.20 + face_quality × 0.15 + technical × 0.15
- fatal_penalties (闭眼 -1.5, 严重模糊 -1.2, 曝光问题 -0.5)
```

**权重动态适配思路**（后续版本）：
- 人像场景：face_quality 权重提升至 0.30
- 风景场景：aesthetic 权重提升至 0.60
- 根据偏好学习结果微调

### 两种力度

| 力度 | 说明 | 淘汰率 |
|------|------|--------|
| 标准 (standard) | 只淘汰明确有问题的 | ~15-25% |
| 进阶 (advanced) | 更积极淘汰 | ~30-45% |

## 云端初筛流程

```
鸿蒙端                          云端
  │                               │
  ├── 选择 200 张照片 ──────────────►│
  │                               ├── 接收缩略图
  │                               ├── quality.py 评分
  │                               ├── 标记 fatal flags
  │                               ├── 返回评分 + flags
  │◄── 返回 {score, flags, reason} ──┤
  │                               │
  ├── 渲染复核页
  ├── 用户恢复部分照片
  │                               │
  ├── 发送保留的照片列表 ─────────────►│
  │                               ├── clustering.py 分组
  │                               ├── 返回分组结果
  │◄── 返回 {groups: [...]} ─────────┤
  │                               │
  └── 进入擂台 PK
```

## 桌面版踩过的坑

1. **美学分高掩盖锐度不足**：NIMA 分高但实际发虚的照片，需要多个信号交叉验证
2. **背影误杀**：背影照的 `eyes_open_score` 低不代表闭眼，需要先判断是否为正面
3. **单人 vs 群像**：合影中一个人闭眼不应该淘汰整张，需要更灵活的面部分析策略
4. **初筛力度不好把握**：宁可少淘汰（标准模式），用户手动补删比漏掉好照片好
